# 🤖 AI Telegram Support Bot

AI-ассистент для автоматизации первой линии поддержки клиентов в Telegram.

Бот самостоятельно отвечает на типовые вопросы, сохраняет контекст диалога и определяет, когда обращение необходимо передать живому менеджеру.

Проект создан как демонстрационный кейс автоматизации клиентской поддержки с помощью n8n + OpenAI + Telegram.

## 🎬 Демонстрация

▶️ YouTube: [Посмотреть работу AI Support Bot](https://youtu.be/WMe5W18dXTo)

## 💼 Какую задачу решает

Бизнесу не всегда нужен сотрудник для ответа на каждый типовой вопрос.

Этот workflow позволяет автоматически:

- принимать сообщения клиентов в Telegram;
- отвечать на вопросы по известной информации о компании;
- сохранять историю диалога;
- собирать данные клиента при записи;
- определять ситуации, когда необходим человек;
- передавать менеджеру обращение вместе с причиной передачи.

## ⚙️ Как работает

1. 💬 Клиент пишет в Telegram
2. 🧠 AI анализирует сообщение и учитывает историю диалога
3. 🔎 Система определяет, нужен ли менеджер
4. 🤖 Если помощь менеджера не нужна — AI самостоятельно отвечает клиенту
5. 👨‍💼 Если помощь менеджера нужна — клиент получает ответ, а менеджеру автоматически отправляется информация об обращении
## 🧠 Пример логики

Если клиент задаёт обычный вопрос, на который у AI есть информация, бот отвечает самостоятельно.

Если клиент хочет записаться, AI последовательно собирает необходимые данные:

- ФИО;
- услугу или врача;
- дату и время;
- телефон.

Только после сбора необходимых данных заявка передаётся менеджеру.

Если клиент задаёт вопрос, который требует участия сотрудника, система автоматически переводит обращение на менеджера.

## 🛠 Стек

- n8n — автоматизация workflow
- OpenAI — обработка сообщений и принятие решений
- Telegram Bot API — общение с клиентом и уведомления
- PostgreSQL — память и история диалога
- Structured Output Parser — структурированный ответ AI

## 📁 Workflow

В репозитории находится очищенная публичная версия n8n workflow:

ai-telegram-support-bot-public.json

Её можно импортировать в n8n и подключить собственные credentials.

Для запуска потребуются собственные подключения:

- OpenAI API;
- Telegram Bot;
- PostgreSQL.

Credentials, токены и данные рабочей инфраструктуры намеренно не публикуются.

## 🔒 Безопасность

Репозиторий содержит демонстрационную версию проекта.

API-ключи, Telegram credentials, данные базы и другие приватные параметры удалены.

Все названия компаний, адреса и бизнес-данные внутри публичного workflow используются исключительно в демонстрационных целях.
